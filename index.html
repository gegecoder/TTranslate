How the rendering pipeline works

译文渲染管线是如何工作的

Every translatable paragraph on the page is collected, then merged into a batch before being sent to the translation service.

收集网页每个可翻译段落，合并成批次后发送给翻译服务。

Block-level paragraphs render as cards, while navigation links render inline to keep the layout intact.

块级段落以卡片形式渲染，导航链接则使用内联译文，保持布局不被撑高。

Results are cached locally, so revisiting a page returns translations instantly.

译文会被本地缓存，再次访问同一页面时几乎瞬间返回。

三步安装，一分钟后开始使用

安装步骤

  1. 打开扩展管理页 在地址栏输入 chrome://extensions/（Edge 为 edge://extensions/）。
  2. 打开开发者模式 在页面右上角开启「开发者模式」开关。
  3. 加载扩展目录 点击「加载已解压的扩展程序」，选择 TTranslate 文件夹，然后把它固定到工具栏。
  4. 开始翻译 打开任意外语网页，点击工具栏图标，按「翻译」或按 Alt + T。
  5. 或直接安装 .crx 包 在 Release 页面 下载最新的 .crx 文件，打开扩展管理页后将其拖入页面即可。

常见问题

打开网页后为什么没有自动翻译？

默认策略是「不自动翻译」，避免在你不想翻译的页面上产生多余的请求。需要在设置里打开「自动翻译网页」，或每次点击翻译按钮 / 按 Alt + T。

用的是哪个翻译服务？需要 API Key 吗？

当前插件默认接入 Bing 免费翻译（edge.microsoft.com），同时保留 Google 免费翻译、MyMemory、Lingva 与本地 LibreTranslate 作为可选项，均无需密钥。

点击翻译没有反应怎么办？

扩展重载后，已打开的标签页不会自动重新注入内容脚本。请刷新页面，或在弹窗中手动点击一次翻译 —— 扩展会先手动注入脚本再执行。

如果仍然无响应，请确认扩展拥有该网站的访问权限，并查看扩展管理页中是否报错。

滚动加载的内容会一起翻译吗？

会。扩展会主动监听新增节点与文本变化，对增量内容进行翻译处理，已翻译过的段落会放入本地缓存，不会重复请求。

翻译面板能否一直开着？

浏览器原生弹窗的位置由浏览器控制，点击页面外就会关闭。点击面板右上角的图钉按钮，会打开一个贴紧屏幕右上角、高度铺满的独立常驻窗口，其中的「翻译 / 还原」仍然作用于原网页。

可以只显示译文、隐藏原文吗？

可以。选择「原处替换」会把译文直接写回原文位置；「原处替换 + 悬停看原文」在替换的同时保留悬停查看原文的能力。再配合 8 种显示主题、字号、颜色与译文位置，可以按阅读习惯自由组合。

为什么有些专业名词没有被翻译？

扩展默认开启「专有名词保护」，会把品牌与技术名词保留原文，避免直译（如把 Spring 译成「春季」），可以在设置中关闭或按您需求调整设置专有名词。

Alt + 点击段落没有反应？

请确认网页翻译面板中的「启用 Alt + 点击忽略」已经打开。忽略状态按域名保存，再次 Alt + 点击同一段即可恢复翻译；刷新页面后依然有效。
